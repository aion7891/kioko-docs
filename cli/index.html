    CLI¶

    kioko serve      [--db PATH | --store URL | --config JSON] [--intelligence | --intelligence-llm MOD:FN]
                     [--host] [--port] [--api-key-env NAME] [--cors-origin O ...] [--allowed-host NAME ...]
                     [--insecure] [--no-mcp] [--mcp-user U] [--mcp-read-only] [--webhook URL ...] [--webhook-secret-env NAME]
kioko ui         [--db | --store | --config | --url URL] [--intelligence] [--agent MODULE:FACTORY] [--open]
                     (+ the serve options except --insecure / --no-mcp)
kioko mcp        [--db | --store | --config | --url URL] [--intelligence] [--user U] [--agent-id A] [--read-only]
kioko recall Q   --user ID [--session S] [--budget N] [--plan] [--json]           [--db | --store | --url]
kioko manage T   --user ID [--reply R] [--session S] [--dry-run] [--json]         [--db | --store | --url]
kioko plan Q     --user ID [--json]                                               [--db | --store | --url]
kioko maintain   [--user ID] [--tasks reflect,pin,link,consolidate] [--json]      [--db | --store | --url]
kioko related ID [--depth N] [--json]                                            [--db | --store | --url]
kioko link A B   [--type T] [--why W] [--remove]                                 [--db | --store | --url]
kioko connect    [--user ID] [--rebuild] [--json]                                [--db | --store | --url]
kioko consolidate [--user ID] [--dry-run] [--json]                                [--db | --store | --url]
kioko kinds | list | search Q | add TEXT | context Q    (--user ID ...)           [--db | --store | --url]
kioko openapi    [--server-url URL]
kioko demo       [--db PATH] [--user ID]
kioko components
    Variable Used by
    KIOKO_API_KEY the server's key, and RemoteMemory's default
    KIOKO_URL connect(), attach() and the CLI commands when no target is given
    KIOKO_DB the default SQLite path
    KIOKO_PG_DSN / DATABASE_URL PgVectorStore() without a DSN
    QDRANT_API_KEY QdrantStore() without api_key=
    KIOKO_USER kioko mcp --user default
